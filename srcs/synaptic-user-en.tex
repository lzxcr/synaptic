\begin{abstract}
  \textbf{synaptic} is a modular \LaTeX3 design system for academic articles,
  books, lecture notes, and technical reports. It requires \texttt{LuaLaTeX}
  with a \texttt{KOMA-Script} document class. This guide covers installation,
  options, and usage.
\end{abstract}

\section{Installation}

Clone the repository and add \texttt{tex/latex/synaptic/} to your \texttt{TEXINPUTS}:

\begin{verbatim}
git clone https://github.com/lzxcr/synaptic
export TEXINPUTS=/path/to/synaptic/tex/latex/synaptic//:$TEXINPUTS
\end{verbatim}

Or install via \texttt{l3build}:

\begin{verbatim}
cd synaptic
lualatex synaptic.ins   # extract .sty files
l3build install          # install to TEXMFHOME
\end{verbatim}

\section{Options}

All options are passed via \texttt{\string\usepackage[key=val,...]\{synaptic\}}.
Runtime changes use \texttt{\string\SynapticSetup\{key=val\}}.

\subsection{Publication Modes (\texttt{mode=})}

\begin{tabular}{lp{0.7\textwidth}}
  \hline
  \textbf{Value} & \textbf{Description} \\
  \hline
  \texttt{journal} & Academic paper. Submission header, abstract, keywords, arXiv. \\
  \texttt{book}    & Monograph or thesis. Chapter headings, running headers, front/back matter. \\
  \texttt{lecture} & Lecture notes. Wide margins, large headings, tcolorbox environments. \\
  \texttt{notes}   & Personal notes. Compact layout, minimal extras. \\
  \hline
\end{tabular}

\section{User API}

\subsection{Metadata Commands}

\verb|\SynapticTitle{text}| --- document title (replaces \verb|\title|).

\verb|\SynapticAuthor[mark]{name}| --- author with optional affiliation mark.

\verb|\SynapticAffiliation[mark]{text}| --- affiliation.

\verb|\SynapticEmail{addr}|, \verb|\SynapticKeywords{...}|,
\verb|\SynapticArxiv{ID}| --- email, keywords, arXiv link.

\verb|\SynapticHeader{text}|, \verb|\SynapticSubHeader{text}|,
\verb|\SynapticPreprint{ID}|, \verb|\SynapticDedicated{text}| --- custom header fields.

\verb|\SynapticMakeTitle| --- render the title page.

\subsection{Customisation}

\verb|\SynapticSetup{key=val}| --- change options after loading.

\verb|\SynapticNewTheorem{env}{Name}| --- declare theorem-like environment.

\verb|\SynapticDefineTheme{A}{B}| --- custom colour theme.

\begin{theorem}[Euler's Identity]
  For any real number \(x\), \(e^{i\pi} + 1 = 0\).
\end{theorem}

\begin{proof}
  Follows from the definition of complex exponentials.
\end{proof}

  \int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
